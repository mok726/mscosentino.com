GuíaGuide · 2008 – 2011

Tres notas de “Cosas que aprendí” sobre PowerShell, escritas mientras armaba scripts de administración para el trabajo.Three “Things I learned” notes about PowerShell, written while building administration scripts for work.

En mi blog empecé a anotar las cosas interesantes que aprendía, sobre todo las que me habían costado entender. Estas tres son de PowerShell.On my blog I started jotting down the interesting things I learned, especially the ones that took me a while to understand. These three are about PowerShell.

IncluyeIncludes

  • El PATH en PowerShell (2008)The PATH in PowerShell (2008) — para ejecutar un script como si fuera un comando, su carpeta tiene que estar en el PATH, aunque estés parado en esa carpeta.to run a script as if it were a command, its folder must be in the PATH, even when you are standing in that folder.
  • Nivel de confirmación (2008)Confirmation level (2008) — el entorno de PowerShell de Exchange tiene $ConfirmPreference en High, por eso pedía confirmación sin que la pidiera; cómo cambiarlo solo durante el script.the Exchange PowerShell environment sets $ConfirmPreference to High, which is why it asked for confirmation unprompted; how to change it only for the duration of a script.
  • Acceder a internet por medio de un proxy (2011)Accessing the internet through a proxy (2011) — cuatro líneas para hacer que un script que descarga datos funcione detrás de un proxy.four lines to make a script that downloads data work behind a proxy.
