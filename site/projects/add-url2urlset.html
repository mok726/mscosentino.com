Add-URL2URLSET

SoftwareSoftware

Script de PowerShell que agrega una URL a un conjunto de URL (URL Set) de Microsoft ISA Server o TMG.PowerShell script that adds a URL to an existing URL Set in Microsoft ISA Server or TMG.

Además de la URL, agrega sus subdominios, y avisa de las entradas que ya existen en lugar de duplicarlas.Besides the URL it adds its subdomains, and it reports any entries that already exist instead of duplicating them.

Debe ejecutarse localmente en el servidor TMG, con el servicio de firewall en marcha.It must be run locally on the TMG server, with the Firewall service running.
