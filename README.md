# mscosentino.com

Static personal site (ES/EN) for Mariano S. Cosentino. Deployed to Azure Static Web Apps from `main`.

- `site/` is what gets published. HTML is generated: edit `build.py`, then run `python build.py site`.
- Photos go in `site/assets/photos/` and are listed per job in `build.py`.
- `_originales/` holds the full-size source photos and is not committed.
